# Lauren John S. Angeles — Portfolio

Dark cinematic portfolio built with Next.js 16, React 19, Tailwind CSS 4, and Framer Motion.

## Prerequisites

- Node.js 20+
- npm

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy

Deploy to [Vercel](https://vercel.com) or any platform that supports Next.js App Router:

1. Push the repository to GitHub.
2. Import the project in Vercel.
3. Use the default Next.js build settings (`npm run build`, output `.next`).

## Customize

- Update `lib/data.ts` for projects, skills, and contact details.
- Add `public/profile.png` for a profile photo (falls back to initials **LJA**).
- **Resume:** drop `resume.pdf` into `public/`, then set `resumeAvailable: true` in `lib/data.ts`.
- Accent color: `#8b5cf6` in `app/globals.css`.
